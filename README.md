# LV/ONGD — Version Premium pour GitHub Pages

Version statique multipage proposée pour l’ONG Lamentation Végétale.

## Pages
- `index.html` — Accueil
- `qui-sommes-nous.html` — Mission, vision et valeurs
- `nos-actions.html` — Domaines d’intervention et projets
- `nous-soutenir.html` — Bénévolat, partenariats et soutien
- `faq.html` — Questions fréquentes
- `contact.html` — Coordonnées et formulaire de démonstration
- `404.html` — Page introuvable
- `assets/css/style.css` — Styles responsives
- `assets/js/main.js` — Menu mobile et interactions simples

## Mise en ligne
1. Téléchargez et décompressez l’archive.
2. Faites une copie de sauvegarde du dépôt actuel avant toute modification.
3. Vérifiez que le dépôt utilise bien le dossier racine ou adaptez le contenu à la source GitHub Pages configurée.
4. Téléversez les fichiers en conservant l’arborescence, puis committez.
5. Vérifiez toutes les pages sur mobile et ordinateur après publication.

GitHub Pages héberge des fichiers statiques. Le formulaire de contact fourni est une maquette et n’envoie aucun message. Pour recevoir des demandes, reliez un service de formulaire ou une API externe. Aucun paiement ni espace administrateur n’est inclus.

## À valider avant publication
- Confirmer l’objectif annuel de 500 arbres avant de le présenter comme engagement officiel.
- Remplacer les images d’illustration par des photos autorisées des activités de l’ONG.
- Vérifier les coordonnées, le statut juridique et les informations institutionnelles.
- Ajouter des rapports, dates, lieux et indicateurs uniquement s’ils sont vérifiés.
- Vérifier les droits d’utilisation des images externes et prévoir une stratégie d’images locales.
- Tester les liens, le contraste, la navigation clavier et les performances.

Les images actuelles sont chargées depuis Unsplash et nécessitent une connexion Internet.
